# 个股量比监测

一个单页的 A 股量比监测看板：输入代码或名称，实时给出当前是**放量**还是**缩量**，以及量比数值和含义。

默认打开的是立讯精密（002475），搜索框里换成任意 A 股代码或名称即可。

## 功能

- **量比实时判断**：量比 = 当日累计成交量 ÷ 前 5 个交易日平均成交量。刻度盘 + 一句话结论，直接告诉你放量/缩量以及大致含义。
- **今日分时量能**：每分钟成交量柱状图，红色为放量分钟，绿色为缩量分钟。
- **近 10 个交易日成交量**：看当天相对近期的位置。
- **日 K 与 KDJ**：近 120 个交易日日 K（红涨绿跌）+ KDJ(9,3,3) 指标，悬停查看当日开收高低、涨跌幅、成交量与 K/D/J。
- **放量/缩量信号回测**：按量比把交易日分成四种量价状态，统计信号出现后 1/3/5 个交易日的平均涨跌与胜率。
- **数据时间戳**：显示行情快照时间和“距今 N 秒”，交易时段内超过 30 秒未更新会标黄提醒。
- **搜索**：支持代码（600519）和名称（茅台），带下拉建议、键盘上下选择、URL `?code=` 分享、本地记忆最近查询。
- **手机可用**：同一 WiFi 下用手机浏览器打开局域网地址即可。

## 运行

### 方式一：本地服务器（推荐）

需要 Node.js 18+。

```bash
node serve.js
```

或者双击 `启动服务器.bat`。启动后终端会打印两个地址：

- 本机：`http://localhost:8080`
- 手机：`http://<你的局域网IP>:8080`

服务器是零依赖的，只用了 Node 内置模块。它做两件事：把 `index.html` 用 HTTP 提供出来、代理腾讯行情接口（绕开跨域和 GBK 编码问题）。

换端口：`set PORT=8090 && node serve.js`。

### 方式二：直接打开 / 静态托管

没有服务器时（`file://` 打开或放在任意静态站点上），页面会自动回落到浏览器直连腾讯接口，功能不受影响，只是少了 `/api` 代理这条更稳的路径。

### 方式三：手机后台常驻

保持运行服务器的窗口不关。手机和电脑连同一个 WiFi，扫不到就用终端里打印的第二个地址。

## 数据来源

腾讯行情公开接口（`qt.gtimg.cn`、`web.ifzq.gtimg.cn`、`smartbox.gtimg.cn`），非官方、不保证稳定，接口变动时可能需要跟着调整。
